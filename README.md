# ImageHub Assets

图片资源仓库，由 Windows 桌面工具 **ImageHub V1.0** 自动维护。

- 只有 `images/` 下的图片会被提交；本地程序数据（数据库、日志、配置）不上传。
- 默认分支固定为 `main`，所有直链都基于该分支，请勿重命名或删除。
- 目录层级按「品类 / 颜色」组织，直链会完整保留相对路径。

## Raw 直链格式

```
https://raw.githubusercontent.com/1224lzc/walmart-images-Auto/main/images/<目录>/<文件名>
```

文件名或目录含空格、中文或特殊字符时，需做 URL 编码（percent-encode）。

## 注意

这是一个 **Public 仓库**：仓库内所有图片、以及 Git 历史中出现过的文件，任何人都能通过 URL 访问。
本地删除图片**不会**删除本仓库中的文件，也不会提交删除操作——历史直链会继续有效。
因此请勿放入不宜公开的素材。

## 目录与命名约定

- 目录与文件名建议使用 ASCII、小写与连字符，避免空格、中文和特殊字符；确需使用时，直链必须做 URL 编码（percent-encode）。
- GitHub 路径**大小写敏感**，仅修改大小写会产生不同的直链，并使旧链接失效。
- 以 `.` 开头的隐藏文件（如 `.gitkeep`）仅用于保留空目录，不属于图片资源。
